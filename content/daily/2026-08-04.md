一、请假入口页重构（select.vue）

**需求**：非学委用户展示三个功能卡片（请假 / 班级列表 / 请假列表）+ 请假规则区。

**改动内容**：
- 移除原有角色过滤的列表式入口，改为三卡片响应式网格布局（移动端单列、桌面端三列）
- 每张卡片：顶部品牌色装饰条 + 标题 + 描述 + 箭头指示
- 请假 → create.vue（学生/学委可用，家长点击提示不可用）
- 班级列表 → class-query.vue（所有角色开放）
- 请假列表 → query.vue（学生/学委可用）
- 下方规则区重新组织为 4 块编号卡片：时长与审批 / 数量与时间约束 / 改期与销假 / 逾期提醒

### 二、班级列表权限开放（class-query.vue）

**需求**：非学委也能查看班级同学请假情况。

**改动内容**：
- 移除 `usePermission().canViewClassLeave` 门禁
- 页面标题改为「班级列表」
- 隐私保护不变：数据契约 `ClassLeaveItem` 在类型层面不包含 `reason` / `attachments`

### 三、桌面端日期选择器问题排查与修复（多轮迭代）

**问题**：`wd-datetime-picker` 在桌面端从底部弹出不合适，需居中显示，但多次尝试后弹窗关不掉。

**排查过程**：

| 轮次 | 方案 | 结果 |
|------|------|------|
| 1 | `transform: translate(-50%,-50%)` + `position: fixed !important` | 弹窗关不掉 |
| 2 | `:has()` 禁用 slide-up 动画改为 fade | 打断 transitionend 回调，关不掉 |
| 3 | flexbox 容器 + `position: relative` 取代 fixed | 布局偏移 + 关不掉 |
| 4 | **根因定位**：create.vue 使用自定义 slot 作为触发器，与 popup 生命周期冲突 | — |
| 5 | **最终方案**：参考 class-query.vue 的默认 wd-cell 方式 | ✅ 正常关闭 |

**最终方案**：
- **create.vue / detail.vue**：日期选择器从自定义 slot 改为默认 `wd-cell` 触发（`label` + `placeholder` + `size="large"`），与 class-query 一致
- **base.css**：仅加居中定位（`top/left:50%` + `translate(-50%,-50%)`），用三 class 选择器提权（0,3,0 > 库的 0,1,0），**不加 `!important`**（加了会阻断 popup 关闭生命周期）
- 标题和按钮强制白色

**关键教训**：
1. wot-design-uni 的 popup 组件对 `!important` 敏感，会打破其关闭生命周期
2. 自定义 slot 方式触发日期选择器在某些场景下与 popup 管理逻辑冲突
3. CSS 选择器优先级（多 class）可以替代 `!important`，同时不破坏组件内部逻辑

## 遇到的问题

**日期选择器弹窗关不掉**：这问题的排查占了大部分时间。核心原因有二：
1. 自定义 slot 触发方式与 popup 生命周期存在兼容问题
2. CSS `!important` 覆盖了库内部的显示/隐藏切换机制

解决思路：回归库的设计模式（默认 wd-cell），CSS 只用选择器优先级不用 `!important`。
