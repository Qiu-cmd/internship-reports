一、登录页优化（`src/pages/login/index.vue`）

**1. 删除 mock 测试提示**

移除页面底部红框标注的 mock 模式使用说明区域。该区域为开发调试用途，正式使用时应不可见。

**2. App 端页面锁定，禁止滚动**

| 问题 | 改动 |
|------|------|
| 页面可上下滑动，表单区域不稳定 | `.auth-page` 改为 `position: fixed; top/left/right/bottom: 0`，完全锁定视口 |
| 卡片贴底，大屏手机上留白不均 | `.auth-body` 改为 `height: 100vh` + `justify-content: center; align-items: center`，卡片垂直水平居中 |
| 表单内容超出视口时不可达 | `.auth-card` 加 `max-height: 100vh; overflow-y: auto`，卡片内部滚动兜底 |

**设计考量**：H5 宽屏样式（`max-width: 440px` 居中卡片）完全保留，上述修改仅在移动端生效，不影响桌面端体验。

### 二、分享海报模块重设计（`src/components/common/ShareSheet.vue` + `src/features/share/`）

**1. 海报风格扩充**

`PosterStyle` 从 4 款扩充为 6 款：

| 风格 | 定位 |
|------|------|
| 简约白 | 正式通知、通用内容 |
| 深空蓝 | 赛事活动首选，暗色科技感 |
| 暖阳橙 | 温暖活力，校园活动 |
| 荣耀金 | 庄重典雅，红榜获奖 |
| 樱花粉 | 柔和亲切，陪伴感 |
| 赛场 | 竞技感，赛事海报专属 |

**2. 海报视觉重设计**

Canvas 和 SVG 两套绘制函数同步重写：

- **渐变背景**：顶部横向渐变条 + 底部纵向淡入
- **装饰元素**：大圆 + 散布小圆点增加层次感
- **中心卡片**：圆角矩形 + 偏移阴影 + 渐变顶条
- **内容标签**：accentSoft 底色 + accent 文字"分享海报"徽章
- **信息层级**：粗体标题 → 分割线 → 摘要 → 引导文案 → 链接
- 去掉原有的"海报风格:xxx"脚注

**3. 布局改为左右分栏**

| 项目 | 之前 | 之后 |
|------|------|------|
| 弹窗高度 | 内容自适应（~40vh） | `min-height: 65vh`，flex 列撑满 |
| 风格选择 | 3 列卡片网格，上下排列 | **左侧单列**垂直排列，96px 宽 |
| 预览区 | 180px 宽、320px 高 | **210px 宽**手机框 mockup、**370px 高** |
| 交互 | 选风格后需手动点生成 | 切换风格**自动**重新生成预览 |

右侧手机框含刘海、圆角边框、底部 home 条，模拟真实设备效果。下方「保存/分享」和「预览」两个操作按钮。

## 遇到的问题

**海报比例协调**：第一版左右分栏预览偏小（140px 宽），看不清海报文字。调整为左侧固定 96px（单列风格名）、右侧 210px 大预览后，视觉效果明显改善。弹窗 `min-height: 65vh` 充分利用屏幕纵向空间。
