登录页 PC 端滚动条与比例适配问题修复

**问题**：PC 端登录页右侧持续存在滚动条，页面可滚动，仅手机登录 tab 勉强正常，邮箱和用户名登录 tab 仍有问题。

**排查过程**（5 轮迭代）：

| 轮次 | 方案 | 结果 |
|------|------|------|
| 1 | CSS `overflow: hidden` 在 scoped 样式中设 `html, body` | 无效 — uni-app 的 `<uni-page>` 使用 shadow DOM，scoped 选择器穿透不进去 |
| 2 | 非 scoped `<style>` 块 + `!important` + `::-webkit-scrollbar { display: none }` | 无效 — shadow DOM 边界仍然挡住了 |
| 3 | JS `onLoad` 中设 `document.body.style.overflow = 'hidden'` | 无效 — `<uni-page>` 是 custom element，JS 拿不到 shadow root 内部 |
| 4 | `pages.json` 加 `"disableScroll": true` | 框架层生效，但内容超出视口时浏览器仍绘制滚动条轨道 |
| 5 | **桌面端等比缩小约 20%** | ✅ 内容自然适配视口，根源上不需要滚动 |

**最终方案**：在 H5 宽屏媒体查询中缩小所有元素比例，让卡片总高度从约 730px 降到约 580px，在 768px 笔记本屏幕上完全容纳。

| 元素 | 之前 | 之后 |
|------|------|------|
| Logo | 120rpx | 88rpx |
| 标题字号 | 60rpx | 44rpx |
| 输入框高度 | 92rpx | 72rpx |
| 验证码图片宽度 | 200rpx | 160rpx |
| 提交按钮高度 + 上边距 | 96rpx + 56rpx | 80rpx + 36rpx |
| 第三方登录圆钮 | 92rpx | 72rpx |
| 卡片内边距 | 48px/40px | 28px/32px/24px |
| 各区域间距 | mb-8/mb-7/my-6 | 统一缩小 |
| 卡片 overflow | `overflow-y: auto` | `overflow-y: visible` |

**关键教训**：uni-app H5 的页面容器使用 shadow DOM，CSS 和 JS 都无法从外部控制其滚动行为。与其跟框架的渲染机制对抗，不如让内容本身适配视口——缩小比例是最可靠的解法。

## 涉及文件

- `src/pages/login/index.vue` — H5 媒体查询中新增比例缩小样式
- `src/pages.json` — 登录页加 `disableScroll: true`
